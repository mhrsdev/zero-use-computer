# computer-use plugin

The Claude plugin for [Zero Use Computer](https://github.com/mhrsdev/zero-use-computer):
the MCP server's entry and the skills (the agent guide, its safety rules and
the design guide). This is the folder the Claude directory installs
(Plugin path: `plugin`).

It carries no program: it runs `computer-use-mcp` from PATH. Install the
program once from the [latest release](https://github.com/mhrsdev/zero-use-computer/releases/latest):
extract the zip for your system and run `install.cmd -NoRegister` (Windows) or
`./install.sh --no-register` (macOS, Linux). That copies it to
`~/.computer-use/bin` and puts it on PATH (on macOS and Linux through
`~/.local/bin`). Then restart Claude Code.

Generated by `scripts/claude-code/sync-plugin.sh`; edit `skills/` at the
repository root, not here.
