# Presentations on Linux (LibreOffice Impress; PowerPoint on the web)

Microsoft PowerPoint has no Linux desktop app. Use **LibreOffice Impress**
(`launch_app("libreoffice --impress")` or `loimpress`) or PowerPoint on the web.

- New `ctrl+n`; open `ctrl+o`; save `ctrl+s` (Keep current format for .pptx);
  Save As `ctrl+shift+s`.
- Slides: new `ctrl+m`; duplicate: Slide ▸ Duplicate Slide; delete: select in the
  panel, `Delete`; reorder by dragging; layout: View ▸ Sidebar ▸ Layouts.
- Text: click a placeholder and `type_text`; `Tab` demotes a bullet level,
  `shift+Tab` promotes; `ctrl+b/i/u`. Outline view (View ▸ Outline) writes many
  slides quickly.
- Objects: `Tab` cycles objects; arrows nudge; Insert ▸ Image / Shape / Chart /
  Table.
- Consistency: edit the Master Slide (View ▸ Master Slide) instead of slide by
  slide.
- Present: from start `F5`; from current slide `shift+F5`; end `Escape`.
- Notes: View ▸ Notes.
- Export: File ▸ Export as ▸ Export as PDF; save a copy before big
  restructures.
- Don't overwrite an existing file silently; read the "Replace?" prompt.
