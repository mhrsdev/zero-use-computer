# Microsoft PowerPoint (Windows)

Views: slide thumbnails on the left, the slide in the middle, notes at the
bottom. `find_element` with the command name ("New Slide", "Layout") is cheaper
than the whole tree.

- New presentation `ctrl+n`; open `ctrl+o`; save `ctrl+s`; Save As `F12`.
- Slides: new `ctrl+m`; duplicate `ctrl+d` (with thumbnail selected); delete:
  select the thumbnail, `Delete`; reorder: drag or `ctrl+shift+Up/Down`; change
  layout: Home ▸ Layout.
- Text: click a placeholder and `type_text`; `Tab` inside a bullet list demotes a
  level, `shift+Tab` promotes; `ctrl+b/i/u`. Use placeholders and Outline view
  (View ▸ Outline) to write many slides quickly: each line is a title, `Tab` makes
  a bullet.
- Objects: `Tab` cycles objects on the slide; arrows nudge; `ctrl+arrows` nudge
  finely; Insert ▸ Pictures / Shapes / Chart / Table; Alt Text via Format ▸ Alt Text.
- Consistency: change fonts/colours in Design ▸ Variants or the Slide Master
  (View ▸ Slide Master) instead of slide by slide.
- Present: from start `F5`; from current `shift+F5`; end `Escape`; Presenter View
  shows notes — opening a show doesn't change the file.
- Notes: click "Click to add notes" under the slide.
- Export: File ▸ Export ▸ Create PDF/XPS, or ▸ Create a Video. Save a copy
  before big restructures.
- Don't overwrite an existing file silently; read the "Replace?" prompt.
