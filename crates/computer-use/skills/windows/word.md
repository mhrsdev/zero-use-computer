# Microsoft Word (Windows)

Word has a ribbon (tabs: Home, Insert, Layout, Review…). `find_element` with the
command name ("Bold", "Page Break") is cheaper than reading the whole tree.

- New blank document `ctrl+n`; open `ctrl+o`; save `ctrl+s`; Save As `F12`;
  print/PDF `ctrl+p`; close document `ctrl+w`.
- Format: bold/italic/underline `ctrl+b/i/u`; heading styles `ctrl+alt+1/2/3`,
  Normal `ctrl+shift+n`; bullets `ctrl+shift+l`; align `ctrl+l/e/r/j`; link `ctrl+k`;
  page break `ctrl+Enter`; copy/paste format `ctrl+shift+c` / `ctrl+shift+v`.
- Editing: find `ctrl+f`; replace `ctrl+h`; go to `ctrl+g`; select all `ctrl+a`; undo
  `ctrl+z`; redo `ctrl+y`; spell check `F7`; word count `ctrl+shift+g`.
- Review: Track Changes `ctrl+shift+e`; comments Review ▸ New Comment. With Track
  Changes on, edits show as markup — say so when reporting, and never "Accept All"
  unless asked.
- Type body text with `type_text` into the page (focus it first by clicking in
  the document area). Newline presses Return (new paragraph); for a line break
  inside a paragraph use `shift+Return`.
- Apply styles instead of manual formatting (Home ▸ Styles) for headings/lists.
- Insert table: Insert ▸ Table ▸ pick size; move between cells with `Tab`.
- Export PDF: File ▸ Export ▸ Create PDF/XPS (or Save As ▸ PDF).
- Protected View / "Enable Editing" bar: a downloaded file opens read-only;
  press Enable Editing only if the user trusts the file.
- AutoSave (OneDrive) saves continuously; "Save a copy" before risky edits.
- Don't overwrite an existing file silently; read the "Replace?" prompt.
