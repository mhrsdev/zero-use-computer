# Microsoft PowerPoint (macOS); Keynote notes at the end

Slide thumbnails are on the left, the slide in the middle, notes at the bottom;
menus are in the menu bar. `find_element` with the command name is cheaper than
the whole tree.

- New `cmd+n`; open `cmd+o`; save `cmd+s`; Save As `cmd+shift+s`.
- Slides: new `cmd+shift+n`; duplicate `cmd+shift+d`; delete: select the thumbnail,
  `Delete`; reorder by dragging; layout: Home ▸ Layout.
- Text: click a placeholder and `type_text`; `Tab` demotes a bullet level,
  `shift+Tab` promotes; `cmd+b/i/u`. Outline view (View ▸ Outline) writes many
  slides quickly.
- Objects: `Tab` cycles objects; arrows nudge; Insert ▸ Pictures / Shapes /
  Chart / Table.
- Consistency: use the Slide Master (View ▸ Master ▸ Slide Master) for fonts and
  colours instead of slide by slide.
- Present: from start `cmd+shift+Return`; from current `alt+cmd+Return`; end
  `Escape`.
- Notes: click "Click to add notes".
- Export: File ▸ Export ▸ PDF; save a copy before big restructures.
- **Keynote** (Apple): same flow — slides navigator on the left, Inspector on
  the right, play `alt+cmd+p`, export via File ▸ Export To ▸ PowerPoint/PDF.
- Don't overwrite an existing file silently; read the "Replace?" sheet.
