# Microsoft Word (macOS); Pages notes at the end

Word for Mac has a ribbon plus the macOS menu bar (File, Edit, View, Insert,
Format…). `find_element` with the command name is cheaper than the whole tree.

- New `cmd+n`; open `cmd+o`; save `cmd+s`; Save As `cmd+shift+s`; print/PDF
  `cmd+p`; close `cmd+w`.
- Format: `cmd+b/i/u`; headings `cmd+alt+1/2/3`; Normal `cmd+shift+n`; align
  `cmd+l/e/r/j`; link `cmd+k`; page break `shift+Return`.
- Editing: find `cmd+f`; replace `ctrl+h`; select all `cmd+a`; undo `cmd+z`;
  redo `cmd+y`; spelling `alt+cmd+l`.
- Review: Track Changes `cmd+shift+e`; Review ▸ New Comment. Edits with Track
  Changes on show as markup — say so; never "Accept All" unless asked.
- Type body text with `type_text` after clicking into the page; newline presses
  Return (new paragraph), `shift+Return` for a line break.
- Use styles (Home ▸ Styles) rather than manual formatting.
- Table: Table ▸ Insert ▸ Table; `Tab` moves between cells.
- Export PDF: File ▸ Save As ▸ File Format: PDF, or Print ▸ PDF ▸ Save as PDF.
- Protected View ("Enable Editing"): only when the user trusts the file.
- **Pages** (Apple): same ideas — menus in the menu bar, `cmd+b/i/u`, Format
  sidebar on the right; export via File ▸ Export To ▸ PDF/Word.
- Don't overwrite an existing file silently; read the "Replace?" sheet.
