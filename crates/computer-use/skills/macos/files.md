# Files and folders (macOS, Finder)

Prefer the tools first: `list_folder` / `read_file` to look, `create_folder` to
make a folder. Use Finder only for what they can't do (move, copy, rename,
trash, open with an app).

- Open Finder: `launch_app("Finder")`. Go to a path: `cmd+shift+g`, `type_text` the path (`~/Documents`),
  `Return`.
- New folder: `cmd+shift+n`, type the name, `Return`.
- Rename: select the item, `Return`, type the new name, `Return`.
- Copy / paste: `cmd+c`, `cmd+v`; **move** with `cmd+alt+v` (paste item here as
  a move). Duplicate: `cmd+d`.
- Trash: `cmd+Delete` (recoverable). Emptying the Trash is permanent — don't
  unless asked. Deleting is a sensitive action: expect a confirmation.
- Quick Look: select the item and press `space`. Get Info: `cmd+i`.
- Search: `cmd+f` in Finder, type, `Return`; Spotlight is `cmd+space`.
- Show hidden files: `cmd+shift+.`.
- Compress: right-click (`perform_secondary_action show_menu`) ▸ Compress.
- Finder shows the path bar with View ▸ Show Path Bar; useful to read where you are.
