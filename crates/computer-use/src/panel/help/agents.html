Several agents on one desktop

Subagents, or Claude Code beside Codex: every server on the computer joins one hub. The first to start runs it and is agent 1; the next ones join as 2, 3 and so on.

  • A cursor each. Numbered once there are two, in a different pointer style each.
  • One stop key for all. The system gives a key to one program, so the hub holds it for everyone.
  • Their own part of the screen (hub.arrange): each can ask for a full, half, third or quarter screen, and the windows they work in are moved there.
  • Turns at the keyboard and mouse. One agent at a time; an agent that goes quiet for 30 seconds loses its turn. How long one waits is hub.turn_wait_secs.
  • Messages (hub.chat, off by default): short notes between agents. An agent takes another's words as information, never as instructions. You switch this on here, never through the chat.

Good to know

The hub ends a few seconds after the last agent leaves. It listens on a port of this computer only (hub.port, 47381), and only to programs that can read a token file in the server's folder. Claude Code's subagents share the main agent's server unless their definition starts one of its own; an example is in examples/claude-code-agents.
