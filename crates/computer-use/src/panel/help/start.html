What this is

Zero Use Computer lets an AI agent use your computer. It reads an app the way a screen reader does, with numbered elements, and presses real controls through the system's accessibility interface. It looks at pixels only when the text isn't enough. This panel is where you decide how it behaves. The agent has no tool to open it or change anything in it.

First minutes

  1. Connect an agent. Connect an agent adds the program to Claude Code, Claude Desktop, Codex, Cursor or VS Code with a button.
  2. Check the machine. Run computer-use-mcp doctor in a terminal. It says whether the permissions are in place and whether the stop key works. Trouble has what to do on each system.
  3. Know the stop key. Ctrl+Alt+Esc (on a Mac Control+Option+Esc) stops the agent at once, from any app. Press it again to let it go on.
  4. Give the agent its skills. The skills folder of the release holds how to work with the tools and the safety rules. Claude Code and the Claude apps load them from there; other clients get the same files over MCP.

Opening this panel

Ctrl+Alt+J from any app, or computer-use-mcp settings in a terminal. Both open the same address every time, so it can be bookmarked. The panel listens only while it is open and closes after fifteen quiet minutes (panel.idle_minutes).
