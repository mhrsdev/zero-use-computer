两个指针，并不相同

智能体有自己的指针，由叠加层绘制在屏幕上。你的真实鼠标指针属于你：大多数动作完全不使用它，因为它们通过无障碍接口按下控件。当某个动作确实需要真实鼠标（按 x/y 坐标点击、拖动）时，程序会移动它，然后把它放回你原来的位置（restore_pointer）。

智能体的指针

自带六种指针：水晶（crystal）、纸张（paper）、果冻（jelly）、冰（ice）、金属（metal）和轨道（orbit），另有普通箭头（classic）。随机（random）为每个会话选一个，同时工作的各个智能体各不相同。每种指针的点击效果各有特色：果冻会被压扁，冰会滴水，纸张会折起，轨道的珍珠会绕着光环转动。选定一种后就不再随机。要为特定智能体指定特定指针，可在设置文件中写入 agent_cursors（见设置文件），例如 { codex = "metal" }。

开启指针动效后，指针移动时会倾斜，留下由自身材质构成的拖尾，等待时还会呼吸。显示按键会在指针旁以键帽形式显示按下的键，输入的文字则在其名称标签下方依次显示。

真实鼠标

开启自然鼠标后，真实鼠标会像人手一样移动：沿平缓的曲线前进，起步快、收尾慢，带有轻微抖动（如果通过鼠标过冲开启，偶尔还会略微越过目标再返回）。有些应用能分辨瞬移的鼠标和人的操作，因此这项默认开启。鼠标只走完最后 70 到 140 px，因为应用只能看到位于其窗口上方的指针；其余路程只会让你的鼠标被占用更久。拖动始终走直线，因为拖动可能会画出一条线。

路径样式

hand（偏向一侧的弧线，带抖动）、sine（横贯路径的波浪）、arc（一段圆弧）、spring（越过目标再回弹，最后停稳）和 spiral（螺旋进入目标）。mixed 每次移动随机选一种。指针和真实鼠标页面上的预览与实际移动鼠标的代码相同，因此每按一次“换一组”都会得到新的样本。
