先运行 doctor

computer-use-mcp doctor 会告诉你缺少什么。它会检查无障碍总线、权限、停止键和此面板的快捷键，并列出无障碍树信息最少的应用。

按系统

  • macOS。为启动服务器的应用（终端、Claude Desktop、Codex、你的编辑器）授予“辅助功能”和“屏幕录制”权限，然后重新启动该应用。停止键是 Control+Option+Esc，而不是 Cmd+Option+Esc，后者是“强制退出”。
  • Windows。无需授权。以管理员身份运行的应用无法被普通进程控制。
  • Linux。需要带有 AT-SPI 无障碍总线的 X11 或 XWayland 会话；原生 Wayland 可在 Hyprland、sway 及其他 wlroots 合成器上使用。没有总线时服务器仍能启动，但没有无障碍树。

常见问题

  • 某个快捷键没有反应。可能被其他程序占用。可在由你掌控中另选一个；doctor 会告诉你哪个被拒绝了。
  • 面板在另一个端口打开。有其他程序占用了 panel.port。此时会改用任一空闲端口，computer-use-mcp settings 会输出地址。
  • Claude Code 提示名称已被保留。较新的版本将 computer-use 留给自己使用。“连接”会改用 zero-use-computer 这个名称添加本程序。
  • 智能体读不懂某个应用。请看应用报告：如果某个应用的查看中“树中信息少”占比很高，它就需要图片。可为它试用“最佳质量”配置方案，或设置 ocr.mode = always。
  • 始终收不到更新。更新需要 curl。更新页面会显示上次检查的时间和结果；立即检查会重新检查并显示错误。
  • 我做的更改被撤销了。以设置文件为准。如果文件有错误，程序会使用默认值，并在日志中说明原因；设置文件会在你输入时进行检查。
