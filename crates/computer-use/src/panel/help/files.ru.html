The server's folder

Everything lives in one folder: ~/.computer-use, or the one named by the COMPUTER_USE_HOME environment variable.

config.tomlThe settings file this panel edits, comments kept.
bin/A copy of the program that the agents are told to start, so the folder you downloaded it to can move.
updates/Downloads waiting, the version kept to go back to, and when it last looked.
icons/The icon of the panel's shortcut.
profiles/Your own profiles, one small file each.
scripts/Scripts the agent saved.
apps.jsonHow often each app needed pixels (screenshot.record_apps).
audit.logThe audit log, if switched on.
hub-47381.token, panel-47382.tokenKeys only you can read, for the hub and this panel.

From a terminal

computer-use-mcp config show            the settings in effect
computer-use-mcp config set screenshot.attach always
computer-use-mcp config check           validate, and report unknown keys
computer-use-mcp doctor                 permissions, stop key, what is set up
computer-use-mcp install --list         which agents are here
computer-use-mcp shortcut --both        an icon that opens this panel
computer-use-mcp update --rollback      go back one version

A running server picks up a change to the settings file by itself (hot_reload). A few settings (the ports, the logging level, the instructions sent when a client connects) are read when a server starts, and say so here.
