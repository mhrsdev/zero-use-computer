Папка сервера

Всё хранится в одной папке: ~/.computer-use или той, что задана переменной окружения COMPUTER_USE_HOME.

config.tomlФайл настроек, который редактирует эта панель, с сохранением комментариев.
bin/Копия программы, которую запускают агенты, чтобы папку, куда вы её скачали, можно было перемещать.
updates/Ожидающие загрузки, версия, сохранённая для отката, и время последней проверки.
icons/Значок ярлыка панели.
profiles/Ваши собственные профили, по небольшому файлу на каждый.
scripts/Скрипты, сохранённые агентом.
apps.jsonКак часто каждому приложению были нужны пиксели (screenshot.record_apps).
audit.logЖурнал аудита, если он включён.
hub-47381.token, panel-47382.tokenКлючи, которые можете прочитать только вы, — для хаба и этой панели.

Из терминала

computer-use-mcp config show            действующие настройки
computer-use-mcp config set screenshot.attach always
computer-use-mcp config check           проверить и сообщить о неизвестных ключах
computer-use-mcp doctor                 разрешения, клавиша остановки, что настроено
computer-use-mcp install --list         какие агенты здесь есть
computer-use-mcp shortcut --both        значок, открывающий эту панель
computer-use-mcp update --rollback      откат на одну версию

Запущенный сервер сам подхватывает изменения файла настроек (hot_reload). Некоторые настройки (порты, уровень журналирования, инструкции, отправляемые при подключении клиента) читаются при запуске сервера, о чём здесь и сказано.
