同一桌面上的多个智能体

子智能体，或 Claude Code 与 Codex 并用：电脑上的每个服务器都会加入同一个中枢。最先启动的服务器运行中枢，成为 1 号智能体；之后的依次以 2 号、3 号等身份加入。

  • 各有一个指针。有两个及以上时会编号，且各用不同的指针样式。
  • 共用一个停止键。系统只会把一个快捷键分配给一个程序，因此由中枢替所有智能体持有。
  • 按需分得屏幕区域（hub.arrange）：只有正在工作的智能体分享屏幕（在 hub.release_after_secs 内没有调用的智能体在下次调用前不分得区域），按各自窗口的需要分配：一个大窗口与两个小窗口并存时，大窗口分得一半，其他各得四分之一。智能体自己移动或平铺的窗口会留在原处，其他智能体分享剩余空间。智能体也可以申请某个区域：全屏、一半、三分之一、四分之一，或 35% 这样的比例。微小变化不会移动窗口，而且窗口只在其智能体下次查看它时才会移动。
  • 轮流使用键盘和鼠标。同一时间只有一个智能体；沉默 30 秒的智能体会失去轮次。最长等待时间由 hub.turn_wait_secs 设定。
  • 消息（hub.chat，默认关闭）：智能体之间的简短留言。智能体把其他智能体的话当作信息，绝不当作指令。此项只能在这里开启，绝不能通过对话开启。

须知

最后一个智能体离开几秒后，中枢就会结束。它只监听本机的一个端口（hub.port，47381），并且只接受能读取服务器文件夹中 token 文件的程序。Claude Code 的子智能体与主智能体共用服务器，除非其定义中自行启动了一个；示例见 examples/claude-code-agents。
