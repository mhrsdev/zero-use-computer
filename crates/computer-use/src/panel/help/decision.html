What it is for

A fast model that answers small typed questions about what is on screen, so the agent doesn't have to read and judge everything itself: yes or no (the probability of yes), one of some options, or a score. Which of fifty reviews are positive; has the page loaded; which element is the add-to-cart button.

It is optional and nothing depends on it. The server also asks it on its own where that saves the agent a turn (decision.auto), answers the same question once for five minutes, and never makes the agent wait on it: after three seconds it judges by itself.

Setting it up

On Decision model, choose Jev (TypeSafe's System One, or a server that speaks its API) or any OpenAI-compatible chat model (OpenAI, Groq, Cerebras, OpenRouter, Ollama, LM Studio). A small, fast model works best. Paste the key and press Save; Test asks it one easy question. The key is saved in the settings file, readable by you only, and is never shown here again, only its last four characters.

What is sent

Only what is being judged: text the agent passes, or a window's elements as text. Private fields are masked first, as for the main model. A key typed here never goes through the chat. You can also keep the key in an environment variable and name it in decision.api_key_env.
