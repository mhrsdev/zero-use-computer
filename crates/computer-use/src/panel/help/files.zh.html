服务器文件夹

所有内容都在同一个文件夹中：~/.computer-use，或 COMPUTER_USE_HOME 环境变量指定的文件夹。

config.toml此面板编辑的设置文件，注释会保留。
bin/提供给智能体启动的程序副本，这样你下载程序时所在的文件夹可以随意移动。
updates/待安装的下载、用于回退的保留版本，以及上次检查的时间。
icons/面板快捷方式的图标。
profiles/你自己的配置方案，每个一个小文件。
scripts/智能体保存的脚本。
apps.json每个应用需要像素的频率（screenshot.record_apps）。
audit.log审计日志（如已开启）。
hub-47381.token、panel-47382.token只有你能读取的密钥，分别用于中枢和此面板。

在终端中

computer-use-mcp config show            当前生效的设置
computer-use-mcp config set screenshot.attach always
computer-use-mcp config check           校验，并报告未知的键
computer-use-mcp doctor                 权限、停止键、已设置的内容
computer-use-mcp install --list         本机有哪些智能体
computer-use-mcp shortcut --both        创建打开此面板的图标
computer-use-mcp update --rollback      回退一个版本

运行中的服务器会自动应用设置文件的更改（hot_reload）。少数设置（端口、日志级别、客户端连接时发送的说明）在服务器启动时读取，并会在此处注明。
