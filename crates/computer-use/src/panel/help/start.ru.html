Что это такое

Zero Use Computer позволяет ИИ-агенту пользоваться вашим компьютером. Он читает приложение так, как это делает экранный диктор, — с пронумерованными элементами — и нажимает настоящие элементы управления через системный интерфейс специальных возможностей. На пиксели он смотрит, только когда текста недостаточно. В этой панели вы решаете, как он себя ведёт. У агента нет инструмента, чтобы открыть её или что-то в ней изменить.

Первые минуты

  1. Подключите агента. Страница Подключить агента одной кнопкой добавляет программу в Claude Code, Claude Desktop, Codex, Cursor или VS Code.
  2. Проверьте компьютер. Выполните computer-use-mcp doctor в терминале. Команда сообщит, выданы ли разрешения и работает ли клавиша остановки. В разделе Неполадки описано, что делать в каждой системе.
  3. Запомните клавишу остановки. Ctrl+Alt+Esc (на Mac Control+Option+Esc) сразу останавливает агента из любого приложения. Нажмите ещё раз, чтобы позволить ему продолжить.
  4. Дайте агенту его навыки. В папке skills релиза описано, как работать с инструментами, и правила безопасности. Claude Code и приложения Claude загружают их оттуда; другие клиенты получают те же файлы через MCP.

Как открыть эту панель

Ctrl+Alt+J из любого приложения, computer-use-mcp settings в терминале или значок на рабочем столе (его можно создать на странице Ярлык на рабочем столе). Каждый раз открывается один и тот же адрес, так что его можно добавить в закладки. Панель слушает, только пока открыта, и закрывается после пятнадцати минут бездействия (panel.idle_minutes).

Куда дальше
