این چیست

با Zero Use Computer یک ایجنت هوش مصنوعی می‌تواند از رایانه‌ی شما استفاده کند. هر برنامه را مانند یک صفحه‌خوان، با عنصرهای شماره‌گذاری‌شده، می‌خواند و کنترل‌های واقعی را از راه رابط دسترسی‌پذیری سیستم فشار می‌دهد. فقط وقتی متن کافی نباشد به پیکسل‌ها نگاه می‌کند. در این پنل تعیین می‌کنید که چگونه رفتار کند. ایجنت هیچ ابزاری برای باز کردن این پنل یا تغییر چیزی در آن ندارد.

نخستین دقیقه‌ها

  1. یک ایجنت وصل کنید. اتصال ایجنت برنامه را با یک دکمه به Claude Code، Claude Desktop، Codex، Cursor یا VS Code اضافه می‌کند.
  2. رایانه را بررسی کنید. در ترمینال computer-use-mcp doctor را اجرا کنید. می‌گوید که آیا دسترسی‌ها برقرارند و کلید توقف کار می‌کند یا نه. در رفع مشکل آمده که در هر سیستم چه باید کرد.
  3. کلید توقف را بشناسید. Ctrl+Alt+Esc (در مک Control+Option+Esc) ایجنت را از هر برنامه‌ای بی‌درنگ متوقف می‌کند. دوباره بزنید تا ادامه دهد.
  4. مهارت‌ها را به ایجنت بدهید. پوشه‌ی skills در بسته‌ی انتشار، شیوه‌ی کار با ابزارها و قواعد ایمنی را در خود دارد. Claude Code و برنامه‌های Claude آن‌ها را از همان‌جا بارگذاری می‌کنند؛ کلاینت‌های دیگر همین فایل‌ها را از راه MCP می‌گیرند.

باز کردن این پنل

Ctrl+Alt+J در هر برنامه‌ای، computer-use-mcp settings در ترمینال، یا آیکونی روی دسکتاپ (میان‌بر دسکتاپ آن را می‌سازد). همه هر بار همان نشانی را باز می‌کنند، پس می‌توانید آن را نشانک‌گذاری کنید. پنل فقط تا وقتی باز است گوش می‌دهد و پس از پانزده دقیقه بی‌کاری بسته می‌شود (panel.idle_minutes).

قدم بعدی

  • مصرف توکن کمتر، اگر هزینه‌ی ایجنت زیاد است.
  • پروفایل‌ها برای تغییر هم‌زمان چندین تنظیم و بازگشت از آن.
  • نشانگر برای انتخاب ظاهر نشانگر ایجنت.
