它的用途

一个快速模型，回答关于屏幕内容的、有固定类型的小问题，这样智能体就不必自己阅读和判断所有内容：是或否（给出“是”的概率）、从若干选项中选一个，或打分。比如五十条评论中哪些是正面的；页面是否已加载；哪个元素是“加入购物车”按钮。

它是可选的，没有任何功能依赖它。在能为智能体省去一轮交互的地方，服务器也会自行询问它（decision.auto）；同一个问题五分钟内只回答一次；而且绝不会让智能体等它：三秒后智能体就自行判断。

设置方法

在决策模型页面，选择 Jev（TypeSafe 的 System One，或支持其 API 的服务器），或任何 OpenAI 兼容的聊天模型（OpenAI、Groq、Cerebras、OpenRouter、Ollama、LM Studio）。小而快的模型效果最好。粘贴密钥并按“保存”；“测试”会问它一个简单问题。密钥保存在设置文件中，只有你能读取，此后不会再在这里完整显示，只显示最后四个字符。

会发送什么

只发送需要判断的内容：智能体传入的文本，或以文本形式表示的窗口元素。与主模型一样，隐私字段会先被遮盖。在这里输入的密钥绝不会经过对话。也可以把密钥放在环境变量中，并在 decision.api_key_env 中填写该变量名。
