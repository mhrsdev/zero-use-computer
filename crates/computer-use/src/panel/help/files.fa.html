پوشه‌ی سرور

همه‌چیز در یک پوشه است: ~/.computer-use، یا پوشه‌ای که متغیر محیطی COMPUTER_USE_HOME نام می‌برد.

config.tomlفایل تنظیماتی که این پنل ویرایش می‌کند، با حفظ توضیحات.
bin/نسخه‌ای از برنامه که به ایجنت‌ها گفته می‌شود اجرا کنند، تا پوشه‌ای که برنامه را در آن دانلود کرده‌اید بتواند جابه‌جا شود.
updates/دانلودهای در انتظار، نسخه‌ای که برای بازگشت نگه داشته شده، و زمان آخرین بررسی.
icons/آیکون میان‌بر پنل.
profiles/پروفایل‌های خود شما، هر کدام یک فایل کوچک.
scripts/اسکریپت‌هایی که ایجنت ذخیره کرده است.
apps.jsonاینکه هر برنامه چند بار به پیکسل نیاز داشته است (screenshot.record_apps).
audit.logگزارش ممیزی، اگر روشن باشد.
hub-47381.token، panel-47382.tokenکلیدهایی که فقط شما می‌توانید بخوانید، برای هاب و این پنل.

در ترمینال

computer-use-mcp config show            تنظیمات در حال اجرا
computer-use-mcp config set screenshot.attach always
computer-use-mcp config check           اعتبارسنجی و گزارش کلیدهای ناشناخته
computer-use-mcp doctor                 دسترسی‌ها، کلید توقف، آنچه راه‌اندازی شده
computer-use-mcp install --list         کدام ایجنت‌ها اینجا هستند
computer-use-mcp shortcut --both        آیکونی که این پنل را باز می‌کند
computer-use-mcp update --rollback      بازگشت به نسخه‌ی قبل

سرور در حال اجرا تغییر فایل تنظیمات را خودش اعمال می‌کند (hot_reload). چند تنظیم (پورت‌ها، سطح لاگ، دستورالعمل‌هایی که هنگام اتصال کلاینت فرستاده می‌شود) هنگام راه‌اندازی سرور خوانده می‌شوند و این را اینجا نشان می‌دهند.
