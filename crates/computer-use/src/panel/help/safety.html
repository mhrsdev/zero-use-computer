What keeps you in charge

  • The stop key. One press stops every agent; every tool call is refused until you press it again. It works from any app. Change it under Your control.
  • It waits for you. Before each action it waits while you are using the mouse or keyboard, and goes on after 1.5 seconds of quiet. Only the system's idle time is read, never what you type or where you click. After two minutes it gives up and tells the agent why.
  • The indicator. While the agent works there is a border, a label and its pointer on the screen. They are click-through and left out of its screenshots.
  • Private data is masked before anything reaches the model: password fields, card numbers (only the last four digits stay) and fields labelled with words like cvv or verification code. Pictures have those areas blacked out. See Privacy.
  • Keystrokes go to the app they are meant for, and typed values are never written to the audit log.
  • The audit log (off by default) is one line a call: the tool, the app and how it ended. Audit log shows it.

What it does not do

This program does not decide which apps the agent may use. That is the job of the security skill the agent loads (skills/computer-use-security), so a client that doesn't load it has no such rule. Hiding a tool from the list, or telling the agent not to use something, is not a lock.

Protected settings

Settings that limit what the agent can do or see, or how the program updates, ask you to confirm each change, and the server asks too, so a page script can't skip it. This panel's own window is refused by every tool, so the agent can't use it to change its own limits.
