Start with doctor

computer-use-mcp doctor says what is missing. It checks the accessibility bus, the permissions, the stop key and this panel's key, and lists the apps whose tree said least.

By system

  • macOS. Give Accessibility and Screen Recording to the app that starts the server (Terminal, Claude Desktop, Codex, your editor), then start that app again. The stop key is Control+Option+Esc, not Cmd+Option+Esc, which is Force Quit.
  • Windows. Nothing to grant. An app running as administrator can't be controlled from a normal process.
  • Linux. An X11 or XWayland session with the AT-SPI accessibility bus; native Wayland works on Hyprland, sway and other wlroots compositors. Without the bus the server still starts, but there is no tree.

Common things

  • A key does nothing. Another program may hold it. Your control lets you pick another; doctor says which was refused.
  • The panel opens on another port. Something else uses panel.port. Any free port is used instead, and computer-use-mcp settings prints the address.
  • Claude Code says the name is reserved. Newer versions keep computer-use for themselves. Connect adds the program as zero-use-computer instead.
  • The agent can't read an app. See Apps report: an app with a high share of looks with little in the tree needs pictures. Try the Best quality profile for it, or ocr.mode = always.
  • Updates never arrive. They need curl. Updates shows when it last looked and what it said; Check now asks again and shows the error.
  • A change I made was undone. The settings file is the truth. If it has a mistake, the program serves the defaults and says why in its log; Settings file checks it as you type.
