Начните с doctor

computer-use-mcp doctor сообщает, чего не хватает. Команда проверяет шину специальных возможностей, разрешения, клавишу остановки и ключ этой панели, а также перечисляет приложения, чьё дерево сообщило меньше всего.

По системам

  • macOS. Выдайте разрешения «Универсальный доступ» и «Запись экрана» приложению, которое запускает сервер (Терминал, Claude Desktop, Codex, ваш редактор), затем перезапустите это приложение. Клавиша остановки — Control+Option+Esc, а не Cmd+Option+Esc, которая вызывает принудительное завершение.
  • Windows. Ничего выдавать не нужно. Приложением, запущенным от имени администратора, нельзя управлять из обычного процесса.
  • Linux. Сеанс X11 или XWayland с шиной специальных возможностей AT-SPI; нативный Wayland работает в Hyprland, sway и других композиторах на wlroots. Без шины сервер всё равно запускается, но дерева нет.

Частые случаи

  • Клавиша ничего не делает. Возможно, её занимает другая программа. В разделе Ваш контроль можно выбрать другую; doctor скажет, какая была отклонена.
  • Панель открывается на другом порту. panel.port занят чем-то другим. Тогда используется любой свободный порт, а computer-use-mcp settings выводит адрес.
  • Claude Code сообщает, что имя зарезервировано. Новые версии оставляют computer-use за собой. Поэтому «Подключить» добавляет программу под именем zero-use-computer.
  • Агент не может прочитать приложение. См. Отчёт по приложениям: приложению с большой долей просмотров, где в дереве мало данных, нужны изображения. Попробуйте для него профиль «Лучшее качество» или ocr.mode = always.
  • Обновления не приходят. Для них нужен curl. На странице Обновления видно, когда была последняя проверка и каков был ответ; Проверить сейчас спрашивает снова и показывает ошибку.
  • Моё изменение откатилось. Истина — в файле настроек. Если в нём ошибка, программа использует значения по умолчанию и пишет причину в журнал; Файл настроек проверяет его прямо во время ввода.
