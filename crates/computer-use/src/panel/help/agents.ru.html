Несколько агентов на одном рабочем столе

Субагенты или Claude Code рядом с Codex: все серверы на компьютере подключаются к одному хабу. Первый запустившийся ведёт его и становится агентом 1; следующие подключаются как 2, 3 и так далее.

  • У каждого свой указатель. Как только агентов двое, указатели нумеруются, и у каждого свой стиль.
  • Одна клавиша остановки на всех. Система отдаёт клавишу одной программе, поэтому хаб держит её за всех.
  • Своя часть экрана по потребности (hub.arrange): экран делят только работающие агенты (тот, кто не делал вызовов hub.release_after_secs, остаётся без части до следующего вызова), каждый — по тому, что нужно его окну: большое окно рядом с двумя маленькими получает половину, а остальные — по четверти. Окно, которое агент сам переместил или упорядочил, остаётся там, где он его поставил, а остальные делят оставшееся. Агент может и сам попросить часть: full, half, third, quarter или долю вроде 35%. Мелкие изменения окна не двигают, и окно перемещается, только когда его агент в следующий раз на него смотрит.
  • Клавиатура и мышь — по очереди. Одновременно только один агент; агент, который замолкает на 30 секунд, теряет очередь. Сколько агент ждёт, задаёт hub.turn_wait_secs.
  • Сообщения (hub.chat, по умолчанию выключено): короткие записки между агентами. Агент воспринимает слова другого как информацию, а не как инструкции. Включается это здесь, и никогда — через чат.

Полезно знать

Хаб завершается через несколько секунд после ухода последнего агента. Он слушает порт только этого компьютера (hub.port, 47381) и только программы, которые могут прочитать файл токена в папке сервера. Субагенты Claude Code используют сервер основного агента, если их определение не запускает собственный; пример — в examples/claude-code-agents.
