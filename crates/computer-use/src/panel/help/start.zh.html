这是什么

Zero Use Computer 让 AI 智能体使用你的电脑。它像屏幕阅读器那样读取应用，为元素编号，并通过系统的无障碍接口按下真实的控件。只有文本不够用时，它才会查看像素。在这个面板里，你可以决定它的行为方式。智能体没有任何工具可以打开此面板或更改其中的内容。

最初几分钟

  1. 连接智能体。连接智能体可一键将本程序添加到 Claude Code、Claude Desktop、Codex、Cursor 或 VS Code。
  2. 检查本机。在终端中运行 computer-use-mcp doctor。它会告诉你权限是否就绪、停止键是否可用。故障排查介绍了各个系统上的处理方法。
  3. 记住停止键。Ctrl+Alt+Esc（Mac 上为 Control+Option+Esc）可在任何应用中立即停止智能体。再按一次即可让它继续。
  4. 为智能体提供技能。发布包中的 skills 文件夹包含使用这些工具的方法和安全规则。Claude Code 和 Claude 应用会从那里加载；其他客户端通过 MCP 获取相同的文件。

打开此面板

在任何应用中按 Ctrl+Alt+J，在终端中运行 computer-use-mcp settings，或点击桌面上的图标（用桌面快捷方式创建）。每次打开的都是同一个地址，因此可以加入书签。面板只在打开时监听，空闲十五分钟后关闭（panel.idle_minutes）。
